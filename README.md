# LABEXTRA_TOTITO

Descripción

Este proyecto es una implementación de un juego de Totito (Tic-Tac-Toe) utilizando React y estilos con CSS puro. Permite jugar entre dos jugadores (X y O) y navegar entre movimientos anteriores.

⚙️ Tecnologías utilizadas

React (useState)

JavaScript

CSS

🚀 Funcionalidades

Tablero 3x3 interactivo

Alternancia automática entre jugadores (X y O)

Detección de ganador

Historial de movimientos

Navegación entre jugadas (time travel)

🧠 Lógica principal

Se maneja el estado del juego con useState

Se guarda el historial de jugadas en un arreglo

Se calcula el ganador con la función calculateWinner

Se permite retroceder a jugadas anteriores

🎨 UI

Diseño centrado con Flexbox

Botones interactivos con hover

Estilo limpio y moderno

▶️ Ejecución
npm install
npm run dev
